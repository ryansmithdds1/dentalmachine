# Dental Machine user manual — How do I…?

One page for each of the 184 things people do in the office, most frequent first. The steps and screenshots come from the measuring robot doing each one in the real app ([how it’s made](../testing.md#user-manual-npm-run-manual)); the same pages are in the app under **Help → How do I…**, where **Print the whole manual** prints all of them (or saves them as a PDF from the browser’s print box).

Anywhere in the app: <kbd>?</kbd> lists the keyboard shortcuts for the screen you are on, <kbd>Ctrl/⌘ K</kbd> opens the command bar (type “how do I …” or “help …” to find a page here), and a green notice with **Undo** (or <kbd>Ctrl/⌘ Z</kbd>) takes back most changes for a few seconds.

If a screen says **“Missing permission: …”**, your role doesn’t include that job — ask the office manager (Settings → Users & roles).

⌨ marks the jobs that can be done from the keyboard alone. Each list is in order of how often the job comes up.
